# Farming-Simulator-2008---PT-BR
Farming Simulator 2008 - Tradução para PT-BR / Farming Simulator 2008 - Translation to  PT-BR

Essa é uma modificação do Farming Simulator com tradução em PT-BR.
OBS: o jogo não suporta certos caracteres, tais como "ç", "é" ou "ã". Então você verá textos sem acentuação.

Para instalar, você deve extrair o arquivo, e rodar o FarmingSimulator2008.exe.
Feito por: Joao.H.T

ENGLISH:

This is a modification for Farming Simulator with a translation into Brazilian Portuguese (PT-BR).
Note: The game does not support certain characters, such as "ç", "é", or "ã". Therefore, you will see text without diacritics (accents).

To install, extract the file and run FarmingSimulator2008.exe.
